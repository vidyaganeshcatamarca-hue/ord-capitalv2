// 01 · Plataforma

Una sola base de código, dos plataformas

Construido con Vite + React 19 y empaquetado con Capacitor para generar apps nativas iOS y Android sin sacrificar la experiencia web. La lógica de negocio es 100% compartida.

Web App

🌐 Navegador

Single Page Application servida desde Vite con React Router 7. Funciona en cualquier navegador moderno y se adapta automáticamente al dispositivo con CSS responsivo.

  • Sidebar fija en desktop (≥768px)
  • Bottom navigation en móvil
  • Lazy loading con React.lazy + Suspense
  • Error Boundary global
Native

📱 iOS & Android

Empaquetado nativo vía Capacitor 7. Acceso a APIs del dispositivo sin sacrificar el rendimiento web. Build con npm run cap:sync.

  • Cámara y micrófono (AudioRecorderModal)
  • Notificaciones push locales
  • Haptic feedback en acciones
  • Filesystem, Share, Network status
Cloud

☁️ Backend Supabase

Toda la persistencia y lógica de negocio vive en Supabase. El cliente solo invoca funciones RPC (nunca accede a tablas directamente), garantizando seguridad a nivel de fila.

  • RPC functions como capa de servicio
  • AuthContext con sesión persistida
  • Realtime para sincronización
  • Row Level Security habilitado

// 06 · Funcionalidades Clave

Lo que hace único a este proyecto

Capacidades transversales que están presentes en toda la experiencia, no en una sola pantalla.

01

Modo Presupuesto Dual

El BottomNav lee la configuración del usuario (fn_obtener_config_presupuesto) y alterna entre vista Base Cero y Anticipado en tiempo real, escuchando el evento budget-mode-changed.

02

Saneamiento Emocional

Flujo de Cuarentena → Bandeja → Audio → Plan de Ataque. Permite registrar acuerdos verbales como audio, congelar gastos impulsivos y atacar deudas con un plan explícito.

03

Análisis BCG del Gasto

Cada movimiento se clasifica en una matriz 2x2 (frecuencia × impacto) para identificar categorías Estrella, Vaca, Interrogante y Perro. Buzón emocional y Hormigas (gastos pequeños recurrentes).

04

Hogar Multi-perfil

El HogarContext comparte balances entre miembros de un mismo hogar financiero. Cada integrante mantiene su AuthContext pero opera sobre los mismos datos.

05

Solo RPC, nunca tablas

Regla de oro: el cliente no accede directamente a tablas. Toda operación pasa por funciones fn_* en Supabase. La app es 100% consumidora de la API de funciones.

06

100% i18n

No existe un string hardcodeado en español en el código. Todo pasa por t('llave') y se resuelve desde es.ts, con 198 fan-in al traductor. La regla es estricta para permitir traducción futura sin refactors.

07

Haptics y feedback nativo

Las acciones críticas disparan vibración háptica (light, success, error) vía @capacitor/haptics. En web, fallback a vibración del navegador. Da respuesta táctil incluso en formularios.

08

Notificaciones Inteligentes

Sistema de useNotificationCount con panel de notificaciones, preferencias granulares, recordatorios automáticos y push notifications vía @capacitor/push-notifications.

09

Lazy Loading Estratégico

AppLayout usa requestIdleCallback para diferir la carga del AddMovementModal hasta que el navegador esté libre. React.lazy en cada Page con Suspense y LoadingSpinner.

10

Diseño Adaptativo

CSS con variables (--blue, --mint, --surface). SideNav aparece en ≥768px, BottomNav en menor resolución. Tema oscuro como base con acentos vibrantes.
