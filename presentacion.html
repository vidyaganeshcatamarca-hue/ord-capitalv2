Auth y Onboarding FLUJO

Autenticación

  • Supabase Auth con flujo PKCE
  • Email/password + Google OAuth
  • Sesión persistente con auto-refresh
  • Route guards: PrivateRoute + PublicRoute
  • Timeout 4s en getSession para evitar bloqueos
  • Nombre usuario desde DB via fn_obtener_nombre_usuario
  • Onboarding optimista con localStorage + RPC retry
  • Trigger fn_handle_new_user captura nombre real de OAuth

Onboarding (3 pasos)

  • Paso 1: Nombre del usuario
  • Paso 2: País de residencia → moneda automática (ARS/USD/EUR...)
  • Paso 3: Creación de 2 cuentas iniciales (principal + efectivo) con saldo opcional
  • Si se omite saldo → flag saldo_inicial_pendiente
  • Desktop: max-width 480px centrado (mobile-first)
  • Mobile: calculadora sin teclado nativo (inputMode="none")

Base de Datos POSTGRESQL

Tablas Principales

  • p_usuariosUsuarios, suscripción, región, moneda
  • p_billeterasCuentas financieras, saldos, moneda, tipo
  • p_cajaMovimientos (ingresos/gastos/transferencias)
  • p_categoriasÁrbol jerárquico de categorías
  • p_presupuestosPresupuestos mensuales por categoría
  • p_sobresSobres de presupuesto con saldo
  • p_tarjetas_creditoTarjetas, cuotas, pagos, compromisos
  • p_hogarHogar/pareja compartida, roles
  • p_inversionesCartera de inversiones
  • p_saludScore diario sanitario + histórico
  • p_preferencias_usuarioPreferencias UI/UX y features

Seguridad y Reglas

  • RLS (Row Level Security) en todas las tablas
  • RPCs reciben auth.uid() — nunca user_id como parámetro
  • Trigger: fn_handle_new_user en INSERT auth.users
  • Cascada de borrado con FOREIGN KEY ON DELETE CASCADE
  • Soft-delete con período de gracia de 30 días

Internacionalización (i18n)

  • Un solo locale: es.ts con 28 secciones (~600+ claves)
  • Sistema t(key, params) con búsqueda recursiva anidada
  • parseError() para errores SQL con parseo JSON
  • Secciones: alerts, bcg, budget, config, familia, inversiones, onboarding, etc.

Utilidades (lib/)

  • format.tsformateo moneda/fecha/número
  • crypto.tscifrado AES, exportación CSV segura
  • haptics.tsfeedback háptico (light/success/error)
  • bcgUtils.tsclasificación BCG, formato ARS, radio burbuja
  • reminders.tsrecordatorios push programados

Evolución del Proyecto HITOS

Más de 25 iteraciones documentadas. Hitos clave:

FEATURE Dos cuentas iniciales en onboarding

Onboarding crea cuenta principal + efectivo con flag de saldo pendiente si se omite.

PERF Precarga del modal Registrar

requestIdleCallback + caché en memoria global para apertura instantánea.

FIX Pantalla borrosa en conciliación

Conflicto de z-index entre CSS lazy-loaded. Homogeneización a z-index 1000/1010.

FIX Nombre usuario OAuth desde DB

Lectura desde DB via fn_obtener_nombre_usuario en lugar de metadata volátil.

FEATURE Filtros persistentes en Home

Periodo, billetera y nivel guardados en localStorage + DB con sincronización diferida.

FIX Consistencia día de ancla

UPDATE en cascada en p_presupuestos al cambiar el día de ancla global del ciclo.
